# ⚡ ThorStation

ThorStation is a single-page website and community resource hub designed for the **AYN Thor** dual-screen handheld.

## 📌 About the Project
This repository hosts the source code for the ThorStation web application. The website serves as a central directory to help users quickly discover the best apps, custom operating systems, and performance configurations for their device.

## 🚀 Features
* 🎮 **Apps & Emulators:** Recommended configurations, GPU driver picks, and performance tweaks.
* 🖥️ **Custom OS:** Directory of Linux builds (e.g., Thorch) and debloated Android ROMs.
* 📱 **Dual-Screen Layouts:** Optimization guides for dual-display setups (3DS and NDS emulation).
* 🔋 **TDP Profiles:** Power presets balanced for battery management or peak performance.

## 🛠️ Tech Stack
* HTML5 / CSS3 / JavaScript (Vanilla)
* Hosted live via GitHub Pages
